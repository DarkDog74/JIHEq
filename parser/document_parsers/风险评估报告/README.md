# 风险评估报告解析器

本目录用于解析“智能体案例”中的风险评估报告。输出结构与定级报告嵌套版一致：

- 一级标题包含二级标题，二级标题包含三级标题；
- 每个章节的 `内容` 数组按原文顺序混合保存段落、图片、表格和子章节；
- 图片提取到同名 `.assets` 文件夹，JSON 中保存可定位的相对地址；
- 表格直接输出命名业务字段和记录，不输出 OOXML 的起始列、跨列数等技术结构；
- 多行表头会合并为 `上级表头·子表头`，空字段和空数据行均保留。

## 单份解析

```text
python convert.py 输入.docx 输出.json
```

## 批量解析

```text
python batch_convert.py
```

默认输出目录为本目录下的 `解析结果_嵌套版`。
