# 符合性评测表证明材料解析器

该解析器只处理“智能体案例”中名称包含“证明材料”或“评测证明”的 Word 文件，自动排除“符合性评测报告”。

输出规则：

- 每个 `XX-XX-XX-XX-XX` 稽核编号或编号组合作为一个独立章节，章节标题只保留编号；
- 编号后的说明文字、答案、截图和表格进入该章节的 `内容`；
- 文档名称等首个稽核项之前的内容进入 `前置内容`；
- 段落、图片和表格按原文顺序混合保存；
- 图片提取到同名 `.assets` 文件夹并在 JSON 中保存相对地址；
- 表格输出业务字段，不输出起始列、跨列数等 OOXML 技术结构；
- 空字段、空数据行和只有图片没有文字的段落均保留。

## 单份解析

```text
python convert.py 输入.docx 输出.json
```

## 批量解析

```text
python batch_convert.py
```

默认输出目录为本目录下的 `解析结果_嵌套版`。
