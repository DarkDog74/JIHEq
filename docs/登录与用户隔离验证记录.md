## 保留的限制

完整测试套件仍存在已在原始源码复现的问题，包括缺少未入库的 ground_truth.v1.json、Windows 不允许包含星号的文件名、Windows 文件权限与路径处理差异。没有通过放宽稽核规则消除这些失败。

未在真实生产材料集上进行准确率评估，未调用真实模型或部署到生产服务器。真实上传联调验证材料识别，未执行原件的完整解析稽核。

本版继续全局同时执行一个任务，按单 API 进程部署；未增加分布式任务队列、多人协作或历史结果版本。部署前停止旧服务、备份 output，安装新增依赖、创建管理员，按部署说明配置 HTTPS、公开源及子路径。

## 复现命令

```bash
python -m unittest tests.test_auth_isolation tests.test_platform_app -q
python -m unittest discover -s tests -q
cd frontend
npm ci
npm run build
# 已安装 Google Chrome 时可使用该环境变量；也可安装 Playwright 自带 Chromium
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e
```

验证使用 Windows、Python 3.12.14、Node.js 24.19.0 和 Google Chrome。项目来自 GitHub main 源码归档，本地 Git 基线用于生成补丁，不是 GitHub 上游提交历史。没有推送远端或修改已部署系统。
